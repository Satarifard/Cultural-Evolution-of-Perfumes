# Notebooks

Each notebook generates one main figure (plus its related supplementary figures).

| Notebook | Generates |
|----------|-----------|
| `Figure_1.ipynb` | Figure 1, S2, S3 |
| `Figure_2.ipynb` | Figure 2, S5, S6, S7, S14 |
| `Figure_3.ipynb` | Figure 3, S8, S9, S10 |
| `Figure_4.ipynb` | Figure 4, S11, S12, S13 |
| `Figure_S1.ipynb` | Figure S1 |

Outputs are written to [`../output`](../output). Unzip `../dataset/Fragrantica.csv.zip` first (see the dataset README).
